Once you download this, just drag it into your scene. Make sure you dont already have one with the same name. 

- Drag it into your /Assets folder, It should compile
- Make a Cube. Set it's box collider to IsTrigger
- Thats the object the player walks into. Position it where ever
- Click add component, Udon Behavior. Drag the Udon Asset into that slot. 
- Make you another cube, mark it as trigger (so you dont walk into it) Put it where you want them to end up after teleport. (Turn it's mesh render off later)
- Link them together
- Add some SFX on it (if you dont want sound, delete that block in the Udon graph or you may be able to leave it blank?
